# Release notes

## Agents as assets (issue #14)

- **Veteran quirks retired.** Combat stats are now a pure function of loadout, gear, and augment levels. Two agents with the same build fight the same way regardless of Service Records (kills, contracts, persuasions). Those records remain ledger and debrief flavor only.
- **Body variants.** Recruits are assigned a male or female cosmetic chassis variant at decant. Existing saves receive a one-time assignment on load. The variant does not affect simulation.
- **Augments read on the body.** Installed augments dress the operative chassis (leg struts, arm plating, torso armor profile, eye glow by version). The equip screen previews the same dress. Rival peer squads on purge/HQ contracts use the same chassis with rival trim and tiered augment reads (full V3 on Act 3 / HQ elites).
